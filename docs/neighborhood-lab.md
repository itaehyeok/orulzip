# 동네 가격 흐름 개발 화면

이 기능은 사용자가 승인한 지도와 근거 설명을 개발 환경에서 개인 검토하기 위한 화면이다. 운영 배포 대상이 아니다. 지도 범위는 송파파인타운 9개 단지다.

## 자료와 계산

- 기본 자료: 앞서 분석에 사용한 실제 `kb_internal_mvp` 발췌 자료. 9개 단지의 전용 84㎡에 가장 가까운 면적형, 2023.01~2026.09 관측값 405개를 `src/fixtures/neighborhood-lab-snapshot.json`에 보관한다. 실시간 자료로 표시하지 않는다.
- `개발 DB` 전환: 운영과 분리된 개발 DB에서 같은 9개 단지의 공통 최신 관측월을 찾는다. 최초 검증 시점은 2026.06이며 화면 출처와 기간이 함께 바뀐다. 운영 DB 연결이나 개발 DB 갱신은 하지 않는다.
- 비교 상대는 최근 6개월을 보기 **전**의 24개월 면적당 중위 시세로 고른다. 같은 법정동, 거리 30~500m, 연식 차이 5년 이내, 면적비 1.15 이내, 비교 상대 300세대 이상, 대상 100세대 이상이다. 상대의 가격 우위가 관측월의 75% 이상, 과거 시세 비율 1.05~1.8이어야 한다. 이 개발 화면의 후보군은 지도에 표시한 9개 단지에 한정한다.
- 기준월까지 최대 36개월 로그 변화율로 관계를 계산한다. 30개월 이상 공동 관측, 각 단지 8개월 이상 가격 변경, 상관 0.4 이상, 베타 0.25~2.5를 요구한다. 결측은 채우지 않는다.
- 빈 원: 비교 상대 상승률 5% 이상, 실제 상승률 차이 5%p 이상, 과거 관계 조정 차이 3%p 이상. 지도 색은 관측 변화의 공간 표현이며 미래 상승 확률이 아니다. 기간 선택은 현재 선정 관계의 재생이며 시점별 백테스트가 아니다.
- 상세 화면에는 거리·면적·연식, 원시 가격, 상관과 관측 수, 직전 12개월 및 전체 18개월 흐름을 함께 표시한다. 실거래 대조 결과는 아직 연결하지 않았다고 표시한다.

기존 테이블을 제한적으로 읽고 메모리에 5분 캐시한다. 개발 DB 질의는 읽기 전용 트랜잭션, 8초 제한, 9개 단지/면적형과 최대 43개 월로 한정한다. 스키마·인덱스·DB 캐시 계약 변경이 없어 마이그레이션은 필요하지 않다.

## 개인 확인 접근

`ORULZIP_ENVIRONMENT=development`와 32자 이상의 개발 전용 `ORULZIP_NEIGHBORHOOD_LAB_TOKEN`이 있어야 활성화된다. 운영 환경에서는 HTML, API, 스크립트, 지도 자료를 모두 404 처리한다. 개발 Compose에만 이 환경변수가 전달된다.

최초 접속은 `/neighborhood-lab?access=<개발용 토큰>`이다. 토큰은 서버의 비공개 `.env`에만 보관하고 저장소/로그에 넣지 않는다. 접속 후 토큰을 URL에서 제거하고 24시간 서명된 HttpOnly/SameSite=Strict 세션을 발급한다. 이후 페이지와 API 및 정적 자료는 해당 세션이 필요하다. 응답은 no-store/no-referrer다. 이 확인 링크를 가진 사람이 접근할 수 있으므로 본인 확인용으로만 보관한다. LAN 원본으로 검토하며 기존 외부 OAuth 게이트는 변경하지 않는다.

정적 지도는 기존 시안의 OpenStreetMap 발췌 도로·공원 자료와 출처 표시를 유지한다. D3 7.9.0은 라이선스와 함께 로컬 제공하며 별도의 외부 지도 키를 사용하지 않는다.

## 검증과 개발 배포

`npm test`, 분리 개발 DB의 `NODE_OPTIONS=--max-old-space-size=4096 npm run check`, Playwright 데스크톱/320·360px 모바일 검사를 수행한다. 모델 수치, 기준시점 이후 가격 변경에 대한 선정 불변성, 결측, 무권한/운영 환경/정적 별칭 차단을 검사한다.

개발 배포는 `docs/DEVELOPMENT_DEPLOYMENT.md`의 락과 격리 규칙을 따른다. 완료 커밋을 `develop`에 통합한 후 그 커밋의 개발 web만 빌드·교체한다. DB/수집기/운영 web을 재시작하지 않는다. 이전 개발 이미지를 롤백용으로 보관한다. 운영 main에는 병합하지 않는다. 개인 검토가 계속되는 동안 태스크 브랜치와 워크트리를 보존한다.

전체 DB 검사 도구는 534만 월별 가격을 한 번에 적재하여 기본 Node 힙(2GB)에서는 메모리 한도에 도달했다. 검사 프로세스에만 4GB 힙을 지정해 정상 완료했다. 새 API는 9개 단지만 읽으며 이 메모리 설정을 요구하지 않는다.
