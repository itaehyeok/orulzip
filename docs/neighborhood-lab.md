# 기존 오를집 지도에서 보는 동네 가격 흐름

이 기능은 사용자가 승인한 지도 표현과 근거 설명을 **기존 오를집 앱의 네이버 지도**에 겹치는 개발 전용 모드다. 운영 배포 대상이 아니다. OpenStreetMap이나 다른 지도 엔진으로 바꾸지 않는다.

## 진입과 접근 제한

개인 확인 링크 `/neighborhood-lab?access=<개발용 토큰>&area=dongtan-station`으로 접속하면 서명된 24시간 HttpOnly/SameSite=Strict 세션을 만들고 토큰을 제거한 `/map?lab=neighborhood&area=dongtan-station`로 이동한다. `area`는 `songpa`(기본), `dongtan-station`, `dongtan-mokdong`만 지원하며 자료 선택도 보존한다. 예전 참고 화면 요청도 같은 기존 앱으로 이동한다. 별도 고정 지도 페이지와 대체 지도 라이브러리는 제거했다.

`ORULZIP_ENVIRONMENT=development`와 32자 이상의 `ORULZIP_NEIGHBORHOOD_LAB_TOKEN`이 있어야 활성화된다. 해당 세션이 있는 개발 요청에만 `/api/client-config`의 `neighborhoodLab.enabled`를 제공한다. 운영에서는 HTML 진입·API·전용 JS/CSS가 404 처리되며 일반 지도 동작은 유지한다. 응답은 private/no-store이며 개인 링크를 저장소나 로그에 기록하지 않는다.

## 네이버 지도 연결

- 기존 앱의 `initNaverZoomMap()`이 만든 `state.zoomNaverMap` 인스턴스와 좌표 투영을 그대로 사용한다. 별도의 지도 인스턴스를 만들지 않는다.
- `DEVELOPMENT_NAVER_MAP_NCP_KEY_ID`에는 기존 앱이 `/api/client-config`로 브라우저에 공개하는 지도 클라이언트 식별자를 연결하고 `DEVELOPMENT_NAVER_MAP_DISABLED=0`으로 켠다. 내부 검토 origin에서 SDK 인증과 실제 타일 로딩을 확인했다.
- 브라우저용 공개 식별자만 연결하며 네이버 서버용 비밀 키는 복사하지 않는다. `DEVELOPMENT_NAVER_MAP_NCP_KEY_SECRET`은 비어 있다. DB·Telegram·MOLIT 자격 증명 격리도 유지한다.
- 지도 설정이 없거나 인증·좌표 준비가 실패하면 기존 네이버 지도 오류를 표시한다. 다른 지도 서비스로 자동 전환하지 않는다.
- 좌표 투영이 준비된 뒤 표시를 시작하며 이동·확대 이벤트는 프레임당 한 번으로 모은다. 기존 지도 연결이 끊기면 표시를 중단한다. 개발 흐름 모드의 초기화 중에는 일반 지도 조회가 끼어들지 않도록 한다.

## 자료와 판단 근거

- 기본 자료는 앞서 분석한 실제 `kb_internal_mvp` 발췌 자료다. 전용 84㎡에 가장 가까운 면적형의 2023.01~2026.09 관측값을 지역별 `src/fixtures/neighborhood-lab-*.json`에 보관한다. 송파 9개 단지의 기존 발췌 자료와 계산은 유지한다. 실시간 자료로 표시하지 않는다.
- 동탄역 주변은 역 주변 반경 1.5km, 동탄 목동은 화성 목동 법정동에 속한 기존 발췌 자료 중 100세대 이상이고 전용 75.6~92.4㎡ 면적형이 있는 단지 전체를 표시한다. 최근 상승 결과나 유리한 관계로 표시 단지를 고르지 않는다. 발췌 자료의 범위이며 해당 지역 전체 아파트를 망라한다고 주장하지 않는다. 지역의 경계·단지 수·관측 범위는 각 파일의 provenance에 기록한다.
- 2026.09 발췌 자료는 동탄역 18개 단지/735개 관측값, 목동 4개 단지/180개 관측값이다. 계산된 관계는 동탄역 2개·목동 0개이며 이 기준월에는 두 지역 모두 빈 원 조건을 통과한 단지가 없다. 신축의 짧은 시세 이력을 채워 넣지 않는다. 개발 DB의 같은 지역 공통 관측월은 최초 확인 시 2026.06이며 화면에 구분 표시한다.
- `개발 DB`를 선택하면 분리 개발 DB에서 선택 지역의 같은 단지들의 공통 최신 관측월을 읽는다. 자료 기준월은 지역과 자료 선택에 따라 표시한다. 운영 DB를 연결하거나 개발 DB를 갱신하지 않는다.
- 비교 상대는 최근 6개월을 보기 전의 24개월 면적당 중위 시세로 고른다. 같은 법정동, 거리 30~500m, 연식 차이 5년 이내, 면적비 1.15 이내, 대상 100세대 이상, 상대 300세대 이상을 요구한다. 상대 가격 우위가 관측월의 75% 이상이고 과거 시세 비율(상대/대상)은 1.05~1.8이어야 한다. 후보는 선택 지역에 표시한 단지에 한정하며 지역 사이에서 비교 상대를 가져오지 않는다.
- 기준월까지 최대 36개월 로그 변화율로 관계를 계산한다. 30개월 이상 공동 관측, 각 단지 8개월 이상 가격 변경, 상관 0.4 이상, 베타 0.25~2.5를 요구한다. 결측은 채우지 않는다.
- 빈 원은 상대 상승률 5% 이상, 실제 상승률 차이 5%p 이상, 과거 관계 조정 차이 3%p 이상일 때 표시한다. 색 번짐은 관측 변화의 주변 표현이며 미래 상승 확률이 아니다. 기간 선택은 현재 선정 관계의 재생이며 시점별 백테스트가 아니다.
- 호버·키보드 포커스로 요약, 클릭·터치로 거리·면적·연식·원시 가격·상관·직전 12개월 및 전체 기간의 반대 근거를 연다. 실거래 대조 결과는 미연결 상태라고 표시한다.

지도 이동과 확대, 흐름 표시 스위치, 기준월 슬라이더, 지역·자료 전환, 기존 검색 입력, 선택 지역 보기를 지원한다. 지역을 바꾸면 이전 표시·검색·근거를 즉시 비우고 새 지역에 맞춰 이동한다. 응답 순서가 바뀌어도 이전 지역 응답은 적용하지 않는다. 지역과 자료 선택은 URL과 로고 링크에 보존한다. 멀리 축소하거나 검증 지역을 벗어나면 없는 자료를 만들어 표시하지 않는다. 조건을 통과한 관계 수와 과거 월별 변화 자료가 부족한 단지 수를 표시하며 원을 만들기 위해 기준을 완화하지 않는다.

## DB 및 검증

기존 테이블을 읽기 전용 트랜잭션으로 조회한다. 8초 제한, 서버의 고정된 지역별 단지/면적형과 최대 43개월 범위이며 결과는 지역+자료 조합별 메모리에 5분 캐시한다. 임의 지역 ID나 파일 경로를 거부한다. 이 모드는 일반 지도 필터의 캐시 생성 경로를 호출하지 않는다. 스키마·인덱스·DB 캐시 계약을 변경하지 않아 마이그레이션은 필요하지 않다.

검증은 Node 테스트, 분리 개발 DB의 `NODE_OPTIONS=--max-old-space-size=4096 npm run check`, 실제 네이버 SDK·타일·원본 인스턴스, 드래그·확대 후 좌표 정합, 호버·근거·기간·자료·검색·모바일 및 개인 접근 제한을 포함한다. 대체 지도 요청이 없고 일반 지도 조회가 중복으로 실행되지 않는지도 확인한다.

개발 배포는 `docs/DEVELOPMENT_DEPLOYMENT.md`의 락과 격리 규칙을 따른다. 완료 커밋을 `develop`에 통합한 뒤 개발 web만 빌드·교체한다. DB·수집기·운영 web을 재시작하지 않으며 `main`에는 병합하지 않는다. 이전 개발 이미지를 롤백용으로 보관하고 개인 검토 중인 태스크 브랜치와 워크트리를 보존한다.
